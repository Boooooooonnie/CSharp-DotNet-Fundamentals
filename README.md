# C# / .NET Programming Fundamentals

A collection of C# programming exercises and Windows Forms applications developed during my .NET programming coursework.

This repository documents my learning process from basic C# syntax and console applications to event-driven GUI development with Windows Forms. It also includes a final project implementing a complete card game with player–computer interactions and game logic.

## Topics Covered

- C# syntax and basic programming concepts
- Console input and output
- Arithmetic and bitwise operations
- Conditional statements and loops
- Methods and parameter passing
- Windows Forms GUI development
- Event-driven programming
- User input and basic validation
- Multi-form applications
- Basic game logic

## Final Project — Ten-and-a-Half Card Game

The final project is a Windows Forms implementation of the **Ten-and-a-Half (10.5) card game**, featuring player-versus-computer gameplay.

The program includes:

- Random card generation
- Player and computer hands
- Card-value calculation, including half-point face cards
- Hit and stand actions
- Bust detection when the score exceeds 10.5
- Win, loss, and draw determination
- Computer card-drawing logic
- Game restart functionality

This project integrates the fundamental C# concepts practiced throughout the course into a complete interactive application.
